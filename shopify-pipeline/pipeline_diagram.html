Listing Mode

py run.py --brand seiko --mode listing

Purpose: Find brand-new products on the Seiko website that don't yet exist in your Shopify store, scrape their details, download their photos, and produce a ready-to-import CSV file.

✅ Use LISTING when…

  • New watches appear on the website
  • You want to add products to Shopify
  • Running your regular refresh schedule

📂 What you get at the end

  • new_products.csv — import into Shopify
  • images/ — downloaded product photos
  • master_catalog.csv — running history
  • run_summary.txt — what happened & counts
0
Startup — Read Config & Set Up Logging
Reads config/seiko.yaml to learn the website URL, which HTML elements contain product data, how to handle anti-bot delays, and what Shopify fields to fill. Creates a log file so you can review what happened. Also creates a timestamped folder inside outputs/seiko/ to hold this run's files.
run.py config_adapter.py reads: config/seiko.yaml creates: logs/seiko_YYYY-MM-DD.log creates: outputs/seiko/YYYYMMDD_HHMMSS/ folder
1
Collect All Product URLs from Seiko Website
Opens a hidden Chrome browser and visits seikousa.com/collections/all. Slowly scrolls down (up to 60 times) to load all products. Then visits the Men's and Women's collection pages separately so it knows which gender each watch belongs to. Extracts every product link and the SKU code from each product card.
url_collector.py saves: urls_collected.txt saves: men_urls.txt saves: women_urls.txt
⚠️ Early exit: If zero URLs are found (website unreachable, anti-bot blocked, or selector broken), the pipeline stops here and writes a summary.
2
Deduplicate — Remove Products Already in Shopify
Opens shopify_exports/seiko_shopify.csv (your current Shopify product export) and compares every collected URL against it. Any product already in Shopify is removed from the list. Only truly new products move forward. The count of new vs. existing is logged.
deduplicator.py reads: shopify_exports/seiko_shopify.csv saves: new_urls.txt
⚠️ Early exit: If all URLs already exist in Shopify (nothing new), the pipeline stops and writes a detailed explanation in run_summary.txt.
3
Scrape Each New Product Page
Visits every new product URL one by one in Chrome. On each page it scrolls slowly to trigger any lazy-loaded content, then extracts:
  • Title — the watch's name
  • Price — current selling price
  • SKU — model code (e.g. SRPL61)
  • Description — product text
  • Specs — movement, case material, diameter, water resistance, etc.
  • Feature bullets — list of key features
  • Image URLs — links to all product photos
Waits 3–6 random seconds between each page to avoid bot detection.
product_scraper.py saves: scraped_products.json
⚠️ Early exit: If all product pages failed to scrape (e.g. all blocked), pipeline stops. Individual page failures are logged as warnings but don't stop the run.
4
Download Product Images
Downloads every product photo to your local computer. Each product gets its own subfolder named after the product handle (e.g. seiko-srpl61). Images are saved in outputs/seiko/images/. Already-downloaded images are skipped so re-running is safe. Waits 0.3 seconds between each image download.
image_downloader.py saves: outputs/seiko/images/{product-name}/photo.jpg
5
Normalize — Clean & Format for Shopify
Transforms raw scraped data into clean, Shopify-ready product records:
  • Cleans up titles (removes junk like "try on your wrist" text, falls back to SKU if needed)
  • Strips currency symbols from prices
  • Assigns gender (Men / Women / Unisex) based on which collection pages it appeared in
  • Builds an HTML spec table (Brand, Model, Movement, Case Material, Diameter, etc.)
  • Combines description + spec table + optional footer into the product's Body HTML
  • Fills all Shopify metafields (band material, dial color, water resistance, etc.)
normalizer.py reads: config/footer.html (if exists)
6
Export Shopify CSV
Writes the finished product data into Shopify's exact 86-column CSV format. Each product becomes one primary row (with all details), plus extra rows for additional images. Products are set to Draft status so they don't go live automatically — you review them first. The CSV is saved in two places: a flat location for easy access, and the timestamped run folder.
exporter.py ⭐ saves: outputs/seiko/new_products.csv saves: outputs/seiko/TIMESTAMP/new_products.csv
7
Update Master Catalog
Updates master_catalog.csv — a running history of every product ever scraped. New products are added with a "first seen" date. Products seen in previous runs get their "last seen" date and run count updated. This builds up over time and gives you a complete picture of your catalog history.
inventory_manager.py ⭐ updates: outputs/seiko/master_catalog.csv
8
Save Run Summary & Copy to "latest" Folder
Writes a run_summary.txt file with a full count of everything that happened: URLs collected, new products found, products scraped, images downloaded, CSV rows exported, catalog totals, and total runtime. Then copies the entire run folder to outputs/seiko/latest/ so you can always find the most recent results without knowing the timestamp.
run_context.py saves: outputs/seiko/TIMESTAMP/run_summary.txt copies everything → outputs/seiko/latest/

Drafting Mode

py run.py --brand seiko --mode drafting

Purpose: Find products that are already in your Shopify store but have been removed from the Seiko website (discontinued, out of stock, etc.) and generate a CSV to set them as Draft so they stop appearing in your store.

✅ Use DRAFTING when…

  • Seiko discontinues a watch model
  • Products disappear from their website
  • You want to clean up your Shopify store
  • Running a periodic "clean-up" sweep

📂 What you get at the end

  • draft_products.csv — import into Shopify to set removed products to Draft
  • Each product in the CSV gets the tag swithommerce_PD added
  • Products are set to Published = FALSE
0
Startup — Read Config
Same as Listing mode — reads config/seiko.yaml and sets up logging. No timestamped run folder is created in this mode.
run.py config_adapter.py reads: config/seiko.yaml
1
Collect All Currently-Live Product URLs
Identical to Listing mode Step 1 — opens Chrome and visits the Seiko website to get a complete, up-to-date list of every product that is currently live on seikousa.com. This becomes our reference of "what is still available."
url_collector.py visits: seikousa.com (live website)
⚠️ Early exit: If zero URLs are collected, we can't determine what's been removed, so the pipeline stops immediately.
2
Find Products in Shopify That Are No Longer on the Website
Opens shopify_exports/seiko_shopify.csv and goes through every product in your Shopify store. For each product, it checks whether its source URL still appears in the list of live website URLs. Any Shopify product whose URL is not found on the current website is flagged as "removed."
deduplicator.py reads: shopify_exports/seiko_shopify.csv
✅ Happy exit: If all Shopify products are still found on the website (nothing removed), the pipeline finishes cleanly with a message "no products to draft."
3
Build Draft CSV — Mark Removed Products
For every product identified as removed, creates a CSV row that sets:
  • Published → FALSE (hides it from the storefront)
  • Tags → adds "swithommerce_PD" to the product's existing tags
When you import this CSV into Shopify, those products automatically move to Draft status. Nothing is deleted — the products still exist in Shopify, just hidden from customers.
drafter.py ⭐ saves: outputs/seiko/draft_products.csv

seiko.yaml — What Each Setting Controls

Config Key What it controls in plain English
🌐 Website Identity
brand Internal code name used for folder names and file names (seiko)
display_name Human-readable brand name used in Shopify product listings ("Seiko")
base_url The root website address — all relative links are resolved against this
🔗 URL Collection — Finding Products
url_collection.primary_url The "all products" page to visit first — this is where all watch URLs are gathered from
url_collection.gender_urls Separate Men's and Women's collection pages — used only to label each watch's gender, not to add new URLs
url_collection.product_link_selector The HTML "address" that tells the scraper where the clickable product links are on the page
url_collection.code_extraction How to read the SKU code from each product card on the listing page (looks at a data-sku HTML attribute)
primary_pagination.type: scroll The page loads more products by scrolling — the scraper keeps scrolling until no more appear
primary_pagination.max_scrolls Maximum number of scroll actions before giving up (60 scrolls = very long pages covered)
primary_pagination.scroll_pause Seconds to wait after each scroll before checking if new products have appeared (3 seconds)
🤖 Browser & Anti-Bot Settings
driver.type: undetected Use a special "stealth" Chrome browser that websites can't easily identify as a bot
driver.first_load_wait Wait 15 seconds after opening the first page — gives the website time to fully load before scraping starts
anti_bot.random_delay_min/max Wait a random 3–6 seconds between visiting each product page, so the scraper looks like a human browsing
anti_bot.slow_scroll Scroll down in small steps instead of jumping to the bottom — triggers lazy-loaded content and looks more human
anti_bot.scroll_pause Seconds to pause between each scroll step (3 seconds)
🏷️ Product Data Selectors — Where to Find Info on the Page
selectors.title HTML location of the watch's name on the product page (tries multiple options as fallbacks)
selectors.price HTML location of the price (e.g. $550.00)
selectors.sku HTML location of the model code (e.g. SRPL61)
selectors.description HTML location of the product description text
selectors.features HTML location of the bullet-point feature list (water resistance, movement type, etc.)
🖼️ Image Settings
image_extraction.method: dom Find images by reading specific HTML elements on the page (as opposed to parsing JavaScript data)
image_extraction.dom_selectors HTML elements that hold the image URLs (wrapper divs with data-src attribute)
image_extraction.exclude_keywords Skip any image URLs containing these words — filters out small thumbnail sizes and mobile duplicates
image_download.referer Pretend the image download request is coming from the Seiko website, to avoid being blocked
📋 Spec Table — Technical Details in Product Description
spec_extraction.type: seiko_dual Seiko pages have specs in two separate sections — the scraper knows to read both and combine them
spec_table.rows Defines exactly which specs to include in the product description table and in what order (Brand, Model, Movement, Case Material, Diameter, etc.)
spec_table.rows[].type: static Always use the same fixed value (e.g. Brand is always "Seiko")
spec_table.rows[].type: scraped Use a value that was scraped from the page (e.g. the SKU)
spec_table.rows[].type: spec Look up a specific spec by name from the scraped spec table (e.g. "Water Resistance")
🛍️ Shopify Settings
shopify.vendor The Vendor field in Shopify — shown to customers as the brand name ("Seiko")
shopify.product_type The product category in Shopify ("Watch")
shopify.status_on_import Products are imported as Draft — they are hidden from customers until you manually publish them
shopify.default_tags Tags automatically added to every product: seiko, japanese-watch, watches
shopify.source_url_metafield Which Shopify metafield stores the original Seiko website URL — this is how the deduplicator identifies already-imported products
